Installing the Slough Drive Practice App

A PWA that installs from Chrome and works like a native app

Step-by-step: GitHub Pages (free)

1. Upload files to GitHub
1Go to github.com and sign in (create free account if needed)
2Click the + icon (top right) → New repository
3Name it slough-drive — leave everything else as default — click Create repository
4Click uploading an existing file (the link in the middle of the empty repo page)
5Unzip SloughDrivePractice_v3.zip first, then drag ALL the files in (including .nojekyll) into the GitHub upload box
6Scroll down, click Commit changes
2. Enable GitHub Pages
7In your repo, click Settings (top tab bar)
8In the left sidebar click Pages
9Under Source, select Deploy from a branch
10Set Branch to main, folder to / (root) → click Save
11Wait ~2 minutes. Refresh the Pages settings page until you see a green banner with your URL:
https://YOUR-USERNAME.github.io/slough-drive/
3. Install on your Android phone
12On your Android, open Chrome (must be Chrome, not Samsung browser or Firefox)
13Type the full URL: https://YOUR-USERNAME.github.io/slough-drive/
14Wait for the page to fully load. A blue "Install app" banner will appear at the top — tap Install
15If no banner appears: tap the ⋮ menu (three dots, top right of Chrome) → tap "Add to Home screen" → tap Add
✓ Done! The app icon now appears on your home screen. Tap it — it opens full screen with no browser bar, uses your GPS live, and caches maps offline.

Why the banner wasn't showing before (fixed in v3)

3 fixes applied in this version:

1. manifest.json start_url — changed from ./index.html to / so Chrome recognises it as installable

2. Icon entries split — "any" and "maskable" must be separate icon entries, not combined in one

3. .nojekyll file added — without this, GitHub Pages' Jekyll processor can corrupt sw.js and manifest.json, making the service worker fail silently and preventing the install prompt

Troubleshooting

Still no banner after loading the page? Try: Chrome ⋮ menu → Add to Home screen. This always works even when the automatic banner is suppressed.

Page not loading? Make sure you included the trailing slash in the URL: .../slough-drive/

GPS not working? The app needs HTTPS — GitHub Pages provides this automatically. If self-hosting, make sure you're on https://

Old version still showing? In Chrome, long-press the app icon → App info → Clear cache, then reopen.
